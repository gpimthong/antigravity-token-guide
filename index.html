1. What Exactly Is an "AI Token"?

Large Language Models like Gemini do not read sentences or whole files like humans do. Text and code are split into small numerical chunks called tokens.

Why Tokens Matter in Software Engineering

In regular English prose, 1 token is approximately 4 characters or 0.75 words. However, in programming code:

  • Indentation & Spaces: Each tab or indentation level can consume tokens.
  • Punctuation & Syntax: Characters like { }, ( ), =>, ; are often individual tokens.
  • Identifiers: CamelCase or snake_case variables (e.g. getUserProfileByTokenId) get split into 4 or 5 tokens!
  • Diffs & File Patches: Showing deleted and added lines doubles the token footprint of code edits.
💡 Quick Rule of Thumb: A typical 300-line TypeScript or Python file is roughly 2,000 to 3,500 tokens.

2. How Tokens Flow Inside Google Antigravity

Google Antigravity is not a standard one-shot chat. It is an autonomous multi-turn agent. Understanding the "Agentic Loop" is key to understanding where your tokens go.

The Compounding Context Phenomenon

Every time Antigravity takes an action (reading a file, checking test outputs, writing code), it executes a turn. On every turn, the entire conversation history, system prompt, and new tool outputs are resent to the Gemini model.

1
Turn 1: User Request & System Initialization
Input: ~8,000 tokens Output: ~150 tokens

What enters the model: The Antigravity system prompt (agent identity, guidelines, available tools like read_file, edit_file, run_command, active skills) + Your initial prompt: "Fix the null pointer in auth.ts".

What Antigravity produces: Chain of thought reasoning + Tool Call: read_file({ Path: "src/auth.ts" }).

2
Turn 2: Tool Execution & File Inspection
Input: ~12,500 tokens (+4,500 file contents) ⚡ 8,000 Cached

What happens: Antigravity's local runner reads src/auth.ts (400 lines = ~4,500 tokens) and feeds the content back into the context.

Gemini decides: The model analyzes the file, discovers the bug, and calls edit_file with the replacement code block (~400 output tokens).

3
Turn 3: Verification with Terminal Command
Input: ~15,000 tokens ⚡ 12,500 Cached

What happens: Antigravity runs npm test auth.test.ts. The terminal stdout and test pass logs (50 lines = ~1,500 tokens) are added to the conversation.

4
Turn 4: Final Summary & Explanation
Output: ~500 tokens Task Complete

The agent responds directly to you explaining what was fixed, linking the changed files, and confirming the test results!

🌟 Why Google Antigravity is so cost-efficient: Prompt Caching!
Because Gemini supports Context Caching, repeating prefixes (system prompt, large codebase files, past steps) get cached on Google's infrastructure. You get charged up to 75% less for cached input tokens instead of full re-reading fees!

3. What Actually Consumes Your Context Window?

Every token in Antigravity belongs to one of five major categories:

1. System & Skills (~5k - 15k tokens)

Agent instructions, safety bounds, tool definitions (read, write, bash), and active skills (e.g. Flutter, Firebase, Web Guidance).

2. Workspace Code (~2k - 100k+ tokens)

Files opened by read_file, directory tree structures, and files you explicitly tagged with @file.

3. Tool Outputs (~1k - 20k tokens)

Terminal command output, build compiler logs, stack traces, and test runner outputs.

4. Agent Thinking & Diffs (~500 - 4k tokens)

The model's internal Chain-of-Thought planning and the exact text/code diff replacements written to disk.

Economics

4. How Does It Cost You? (Billing & Plans)

How you are charged depends on how you access Google Antigravity:

Plan A: Subscription / Quota Based

(e.g., Google One AI Premium, Gemini Advanced, Workspace Enterprise, or Developer Preview)

  • Flat Monthly Fee: You pay a fixed subscription fee (e.g. $20/month) rather than per-token invoices.
  • Rate Limits: Governed by TPM (Tokens Per Minute) and RPD (Requests Per Day).
  • No Surprise Bills: You won't get an unexpected credit card charge if an agent runs a 20-step loop. If you hit limits, the agent briefly cools down.

Plan B: Pay-As-You-Go API / Vertex AI

(When connecting custom Google Cloud Vertex AI credentials or Gemini API keys)

  • Billed per 1 Million Tokens (MTok): Micro-metered based on exact Input, Cached Input, and Output counts.
  • Output Tokens Cost More: Generating code takes ~3x to 4x more computation than reading files.
  • Huge Caching Discounts: Long conversations benefit from cached prompt pricing.

Best Practices

6. How to Optimize Token Usage in Google Antigravity

Save money and avoid hitting quota rate limits with these built-in Antigravity features:

Built-in Command

Use /compact on Long Chats

When a debugging session gets long (10+ turns), run /compact. Antigravity synthesizes the entire conversation into a concise factual summary, resetting the massive context snowball.

Subagents

Delegate Heavy Research

When you invoke a research subagent, it runs in an isolated branch context. Hundreds of raw file reads stay inside the subagent and only the final concise answer returns to your main session!

Context Hygiene

Target Specific @ Mentions

Instead of saying "look at my whole project", type @src/utils/math.ts. This prevents the agent from reading 30 irrelevant files and preserves your token budget.

Model Strategy

Flash for Edits, Pro for Architecture

Keep Gemini Flash as your default for everyday coding, unit tests, and routine bugfixes. Switch to Gemini Pro only when tackling complex system refactors.

Terminal Safety

Limit Verbose Test Logs

If running terminal commands, filter verbose outputs: npm test -- -t "specificTest" rather than running 5,000 tests that vomit 50,000 tokens of stdout.

Session Lifecycle

Start a New Conversation

Once a feature or bugfix is completed, hit New Conversation. Carrying finished tasks into a new task forces the agent to re-read old code on every single turn.
