# Google Antigravity Token & Cost Guide ⚡

An interactive visual guide explaining how AI tokens work, agentic context compounding, pricing models, and token cost optimization in **Google Antigravity**.

## 🌟 Features Included

- **Interactive Tokenizer Sandbox:** Live character-to-token converter demonstrating how Gemini splits programming syntax, whitespace, and natural language.
- **Agentic Loop Visualizer:** Step-by-step breakdown of how multi-turn agent execution compounds context and how Gemini Prompt Caching saves up to 75% on repeated prefixes.
- **Dynamic Cost & Quota Calculator:** Real-time estimation of input, output, and cached tokens across Gemini Flash and Gemini Pro models.
- **Cost Optimization Guide:** Actionable best practices (using `/compact`, subagent delegation, targeting `@` mentions).
- **FAQ Accordion & Theme Switcher:** Instant answers to common developer quota and billing questions, supporting both Dark and Light modes.

## 🚀 Live Demo & Local Usage

Open [`index.html`](index.html) directly in any modern browser:

```bash
# On macOS:
open index.html

# Or with a local HTTP server:
npx serve .
```
